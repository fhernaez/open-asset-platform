# Prompt inicial para pegar en la ventana de Kilo Code

Construí integralmente Open Asset Platform según este workspace. Leé AGENTS.md, CONTEXT.md, prompts/SYSTEM.md, docs/architecture/MASTER_ARCHITECTURE.md y la matriz de requisitos. Empezá con `/oap-start`, creando primero `.venv` y auditando el sandbox. Implementá el trabajo por hitos de docs/plan/BUILD_ORDER.md, delegando subagentes para diseño, Django, IoT, frontend y QA cuando sea posible, pero verificando cada integración antes de continuar. No saltar gates ni presentar stubs como funcionales. Django debe implementarse SIN dependencia operativa de OpenRemote/Atlas. La primera ejecución Docker debe crear DB/roles/extensiones/migraciones automáticamente e idempotentemente. MQTT Agent y Attributes con `storageDatapoint` deben soportar nativamente ON CHANGE y máximo N muestras/ventana T, sin Node-RED. Mantené docs/evidence/IMPLEMENTATION_STATUS.md y dejá comandos exactos para reproducir el resultado. Nunca avances a un siguiente hito con requisitos bloqueantes sin explicarlo y solicitar revisión.
