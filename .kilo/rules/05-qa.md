# Prohibido afirmar funcionalidad sin ejecutar pruebas
- Cada requisito: test positivo, negativo, de autorización y, si aplica, de restart/replay/migration.
- Gates G0-G9 según `docs/quality/GATES.md`; guardar comando/resultado y no ocultar fallas.
- No test solo de mocks para decir integración, ni saltar frontend si el acceptance involucra GUI.
- Si hay flakiness, investigarla; no excluir tests silenciosamente. Bloquear release ante vulnerabilidades críticas.
