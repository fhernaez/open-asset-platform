# Contribución al proyecto OAP

Repositorio FOSS público con licencia pendiente de fijar tras auditoría (leer `docs/legal/LICENSING_AND_CLEAN_ROOM.md`). No contribuir código de funciones comerciales de terceros sin derecho de redistribución.

Antes de PR: crear `.venv`, ejecutar gates apropiados, vincular REQ IDs, contratos, tests y evidencias. No modificar arquitectura sin ADR, no escribir en tablas privadas ajenas, no secretos en Git, no reemplazar integración real por mocks.

Para código contribuidor: revisión independiente de seguridad/tenancy y compatibilidad de plugins, migraciones y backwards compatibility. Documentar cambios visibles de UI ES/EN.
